# Data Viz Exports

This directory contains visualization-ready CSV datasets exported from the Nalex data pipeline.

## Quick Start

1. **Regenerate all exports:**
   ```bash
   cd /path/to/nalex
   python scripts/generate_viz_exports.py
   ```

2. **Load into Claude Codes:**
   - Open Claude Codes with data viz plugin enabled
   - Load any `.csv` file from this directory
   - Reference `viz_manifest.json` for dataset metadata

3. **Example queries:**
   - "Show me the timeline of events by speaker"
   - "Plot theme frequency by phase"
   - "Compare sentiment scores between Alex and Naomi"
   - "Visualize gap analysis: expected vs actual communication"

## Datasets

| File | Rows | Description |
|------|------|-------------|
| `events_timeline.csv` | *variable* | Flattened event timeline with standardized columns |
| `theme_metrics.csv` | *variable* | Communication theme frequency and sentiment |

| `gap_analysis.csv` | *variable* | Expected vs actual communication gaps |
| `orphan_events.csv` | *variable* | Events without proper timeline relationships |

## Column Conventions

- **timestamp**: ISO 8601 format (YYYY-MM-DDTHH:MM:SSZ)
- **speaker**: Normalized values: `alex` | `naomi` | `system` | `unknown`
- **event_type**: From `schema/nalex_semantic_schema_v2.md`
- **phase**: Relationship phase identifier
- **loop_id**: Communication loop identifier (if applicable)
- **metadata_json**: JSON string of remaining fields

## Schema Reference

- **Semantic schema**: `schema/nalex_semantic_schema_v2.md`
- **Viz schema**: `schema/viz_schemas/nalex_viz_schema.json`
- **Manifest**: `viz_manifest.json` (auto-generated)

## Troubleshooting

**Missing data in CSVs:**
- Check that source JSON/JSONL files exist in `data/raw/` and `data/derived/`
- Run the export script and check for warning messages

**Column names don't match:**
- The export script uses flexible key matching (tries multiple possible field names)
- Check `metadata_json` column for unmapped fields

**Orphan events not updating:**
- Ensure `analysis/audits/nalex_orphan_event_mapping_*.csv` exists
- The script automatically picks the most recent file
